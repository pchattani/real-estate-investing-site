# Real Estate Investing (site)

Static analytics site built from open sold-price registers and official statistics. This repository holds
only the published pages and data; the engine that produces them is private.

What is here: repeat-sales indices to postcode-district level with uncertainty bands and an explicit
provisional tail, sold-record histories, price tiers and segments, seller outcomes, an H3 hex map, and a
country layer with a templated global read. See the Methodology page on the site.
